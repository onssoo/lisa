## Notes for the record (not blockers)

1. **Pairing stores the raw token in `ops.meta`** (`pair_raw:<code_sha>`, deleted on redemption,
   line 173/196). It works, but the contract says tokens are stored **hashed only** (§6: `token_sha256`,
   and "only their hashes are stored" in design §3.4). The raw-in-meta stash is a 10-minute window
   with DB access, so exposure is small, but it is a spec deviation the reviewer should see and either
   bless (as a P0 simplification) or ask to be replaced (e.g. return the token once at pair time and
   never store it). Flagging, not blocking.
2. **`make node` target exists in the Makefile but no-ops from the repo root** (`No rule to make
   target 'node'` — the real build is `node/scripts/build-node.sh`). One-line Makefile fix or drop the
   stale target.
3. **CLT is still 5.8.1 / SDK 13.3.** The macOS 14 permission branch therefore cannot compile yet.
   Plan v2 F3's documented-deviation route applies: either install CLT 15.x before P1, or record the
   one-line §1 deviation and add the branch at M0 on the mini. Owner decides (it's the owner's Apple ID
   download).

   web health page is the P0 deliverable and works.
